# РК 3 — состав и проверка

Подготовлено 24 ноября 2026 года для просмотра перед публикацией.

## Перенос исходника

Источник — предоставленный файл `RK_3_MPF.docx`, SHA-256 указан в `import-summary.json`.
Перенесены 157 вопросов, 665 вариантов и 157 выделенных ответов. Учтены все 823 непустых абзаца исходника: заголовок, формулировки и варианты. В файле нет явных номеров вопросов; ID назначены по порядку документа, включая повторы.

Варианты в абзацах 157 и 194 (счёт с единицы) оформлены как обычный текст, а не список. Они присоединены к соответствующим вопросам. В заданиях 26 и 32 исходная нумерация вариантов имеет пропуски: 1, 2, 4 и 1, 2, 3, 5. Имеющиеся варианты сохранены полностью, отсутствующие не восстановлены догадками; особенности отмечены в банке.

Три пары полных повторов сохранены: 81/101, 83/102, 85/103. Ключи внутри этих пар совпадают. Совпадения только формулировок при разных вариантах перечислены отдельно в `import-summary.json` и не удалялись.

Вопросы 28, 38, 41, 55, 109, 131 и 143 отмечены для предметного уточнения. Все ключи сохранены по выделению в Word. Проверка переноса не удостоверяет медицинскую правильность ключей; окончательная сверка этих семи заданий с преподавателем остаётся открытой. Новые медицинские ответы в банк не добавлялись.

`question_audit.csv` содержит по одной строке на каждое из 157 заданий. Сохранённые в DOCX маркеры страниц приведены только как вспомогательный ориентир с явной пометкой об отсутствии верификации; это не ссылки на заново отрендеренные страницы.

## Изменения сайта

- Добавлены `rk3.html` и `data/rk3-questions.js`, карточка быстрого входа, поиск и доступная вкладка РК 3.
- РК 3 использует общий движок и собственные ключи прогресса и активной попытки. Банки РК 1 и РК 2 не изменены.
- Примечания с ключами видны в банке и разборе; при решении вопроса показываются после проверки в тренировке. В экзамене до завершения они скрыты.
- Обновлён кэш приложения, добавлены ресурсы РК 3. При переходе без сети на ссылку с `?mode=exam` используется сохранённая страница нужной РК.
- На телефоне подписи вкладок сокращены до «РК 1», «РК 2», «РК 3»; полные подписи сохранены для средств доступности. Все три вкладки помещаются на экране шириной 390 px. Использована существующая дизайн-система.

## Выполненные проверки

1. Независимый XML-парсер сравнил все 157 формулировок, 665 вариантов и 157 ключей с Word. Проверены непрерывность ID, ручные варианты, повторяющиеся задания и 157 строк аудита.
2. Девять автоматических тестов общего движка и ресурсов прошли. Для всех 157 заданий проверены верный и неверный ответы, перемешивание вариантов и повтор ошибок. Проверены восстановление попытки без двойного учёта, независимость и сброс прогресса, экзамен с пропусками, истёкший таймер, прежние банки с заданиями на последовательность и соответствие, наличие локальных ресурсов и офлайн-ссылка с параметром режима.
3. В настоящем браузере пройдены поиск РК 3, открытие тренажёра, верный и неверный ответы, перезагрузка с продолжением, исправление ошибки, поиск в банке, раскрытие примечания, экзамен без подсказки, завершение и разбор 157 заданий. После проверки пробный прогресс сброшен.
4. Каталог и стартовый экран проверены на ширинах 390, 760, 1100 и 1440 px; горизонтального переполнения страницы нет. На экране вопроса 390 px размер текста вариантов 16 px, сенсорные зоны не менее 52 px; навигация вопросов сворачивается при рендере на телефоне. Исправленная мобильная вкладка РК 3 проверена повторно.
5. Синтаксис изменённых JavaScript-файлов и `git diff --check` проверены. В журнале браузера на момент проверки ошибок и предупреждений не было.

Офлайн-переход проверен автоматическим тестом обработчика service worker; установка приложения и работа при реальном отключении сети в браузере в эту проверку не входили.
